# facebook_UI-clone

This is a simple Facebook-inspired UI project that I built while learning HTML and CSS.

The main focus of this project was to practice building a responsive layout and understand how different CSS properties work together.

## Features

- Facebook-style navigation bar
- Responsive design for desktop and mobile
- Story cards with images and profile pictures
- Horizontal scrolling stories on mobile
- Hover effects
- Different navbar layouts for desktop and mobile

## What I used

- HTML
- CSS
- Flexbox
- CSS positioning
- Media queries

This is still a learning project, and I plan to keep improving it as I learn more HTML, CSS, and JavaScript.

## Preview

The project currently includes a responsive navigation bar and a Facebook-style stories section.
